# 流体工厂（Fluid Factory）

流体默认只有两种……好吧，两种类型：普通型（plain），和世界型（可流动）。

为了支持流动流体及其他自定义流体实现，流体类型还提供了一些额外的字段，可以触发不同的行为。

未来可以根据需要添加更多类型。

## "plain"

默认流体类型。只能存在于容器中，不能放置在世界中。

没有默认的 FluidState 属性。

## "flowing"

一种可以放置在多个方向的方块流体，包括向上和向下。

可以放置在世界中。

默认 FluidState 属性：`level`（必填，不可移除）。

流动流体有一些普通流体没有的额外参数。

```json
{
  ...
  "block": true,
  "can_convert_to_source": false,
  "slope_distance": 4,
  "dropoff": 1,
  "tick_delay": 5,
  "explosion_resistance": 100
}
```

### "block"

定义流体的可放置方块。

可选。默认：无方块。若不使用，流体将无法存在于世界中。

可以是 2 种形式之一：
* 布尔值：若为 `true`，流体方块将使用全部默认属性。
* JSON 对象（`{}`）：包含方块定义的各字段（见 [方块](./Blocks.md) 页面）。内联的方块定义中不允许包含 `"fluid"` 字段。

### "can_convert_to_source"

定义当两个源方块相隔 1 格时，流体能否形成新的源方块。

可选。默认：false（不产生源方块）。

必须是布尔值（`false` 或 `true`）。

### "slope_distance"

定义游戏在寻找流体可以流过的空洞时的扫描距离。

可选。默认：4。

必须是大于零的整数。

### "dropoff"

定义流体每向外扩散一格时，液位下降的量。

可选。默认：1。

必须是介于 1 与 8 之间的整数。

### "tick_delay"

定义游戏在两次流体更新之间等待的时间。

可选。默认：5。

必须是大于或等于零的整数。

### "explosion_resistance"

定义爆炸经过流体方块时被削弱的程度。

可选。默认：100。

必须是数字。
